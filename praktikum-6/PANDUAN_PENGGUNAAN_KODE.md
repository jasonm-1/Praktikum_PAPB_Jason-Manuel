Link github ini dibuat untuk menyertakan kode program yang jumlahnya cukup banyak dan sangat tidak efisien jika semuanya disertakan di dalam laporan praktikum.

Ketika mengakses kode program di dalam github, pertama-tama buat Activity baru terlebih dahulu. Jika file yang dicantumkan sudah ada dari default saat pertama kali membuat Activity, maka langsung ganti isi file default tersebut dengan file yang disertakan di github. Jika belum ada, maka buat folder, lalu buat file dengan isi yang diberikan pada kode program di github. 

File yang diberikan pada kode program hanya file yang berpengaruh pada kesesuaian instruksi. Jika file yang ditemukan pada Android Studio tidak disertakan di dalam link folder github ini, maka bisa gunakan isi file bawaan ketika membuat Empty Activity pada Android Studio.

Pastikan semua file dibuat di dalam package yang sama (com.example.(nama package)). Pastikan juga semua syntax "package com.exampe.(nama package)" dan "import com.example.(nama package)" diganti sesuai dengan nama package yang dibuat masing-masing.
